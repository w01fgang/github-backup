- `blocking:` — code regression, security defect, data loss, "feature literally doesn't work as documented".
- `env:` — operator-skipped prereq, env var unset, transient infra hiccup.
- `doc:` — typo, outdated example, instruction unclear.
- `infra:` — DNS propagation timing, ACME challenge slow, droplet under load.
