<hook_design_notes>
The hook uses `--check` mode (which doesn't mutate README.md and exits non-zero on staleness), so the hook itself doesn't have to clean up after a failure. The error message includes the exact remediation command.

`git diff --exit-code README.md` would also work but mutates README.md when stale — `--check` mode is cleaner: no temp state on rejection.

If `scripts/sync-readme-manifest.ts` is itself missing (e.g. on a checkout from before Phase 8 landed), the hook should print a clear "skipping droplet-manifest check (script not present)" warning and exit 0 — don't break commits on branches that pre-date Phase 8.
</hook_design_notes>

<prepare_script_design>
`package.json#scripts.prepare` runs automatically on `npm install`. The script must:
1. Be a no-op if `.git/` doesn't exist (e.g. CI clones with `--depth=0` plus `git init` workflows, or installs into a tarball-extracted dir).
2. Always overwrite `.git/hooks/pre-commit` (idempotent — last-write-wins is fine because the source is committed).
3. `chmod +x` the destination.

Implementation: a single bash one-liner is acceptable. Use `node -e` for cross-platform safety. Example:

```json
"prepare": "node -e \"const fs=require('fs'),p=require('path'); const src=p.resolve('scripts/git-hooks/pre-commit'); const dst=p.resolve('.git/hooks/pre-commit'); if (!fs.existsSync('.git') || !fs.existsSync(src)) process.exit(0); fs.copyFileSync(src, dst); fs.chmodSync(dst, 0o755); console.log('✓ installed .git/hooks/pre-commit');\""
```

(Plan executor: feel free to extract this to `scripts/install-hooks.ts` if the inline JSON-escaped string is too brittle — the truth that matters is *the file gets copied + chmod'd on npm install*.)
</prepare_script_design>

<action>
Create directory `scripts/git-hooks/` and file `scripts/git-hooks/pre-commit` (no extension):

```bash
#!/usr/bin/env bash
# scripts/git-hooks/pre-commit
#
# Phase 8 (MANIFEST-03 / D-07 / D-08): enforce that README.md's
# droplet-manifest managed section is in sync with scripts/lib/droplet-manifest.ts
# before the commit lands locally. The CI workflow (.github/workflows/sync-check.yml)
# catches --no-verify bypasses.
#
# Installation: `npm install` triggers the `prepare` script which copies this
# file to .git/hooks/pre-commit and chmods +x.
#
# Skips silently if scripts/sync-readme-manifest.ts is not present (e.g. checking
# out a branch that pre-dates Phase 8) — don't break commits on legacy branches.

set -euo pipefail

if [ ! -f scripts/sync-readme-manifest.ts ]; then
  exit 0
fi

if ! npx --no-install tsx scripts/sync-readme-manifest.ts --check; then
  echo "error: README.md droplet-manifest section is stale; run 'npm run sync:readme' and re-stage" >&2
  exit 1
fi
```
</action>

<task id="04-03">
<title>End-to-end pre-commit hook test (mutate manifest, attempt commit, expect rejection)</title>
<read_first>
- scripts/lib/droplet-manifest.ts
- README.md (managed section from Plan 03)
- scripts/git-hooks/pre-commit
- .git/hooks/pre-commit (installed by Plan 04-02)

<action>
Execute a self-contained shell sequence that:
1. Saves the current `scripts/lib/droplet-manifest.ts` to `/tmp/manifest.bak`.
2. Appends a dummy optional entry to the `optional` array.
3. Stages the manifest change WITHOUT running the sync script.
4. Attempts `git commit -m 'phase-8 hook smoke test'` — MUST fail with the staleness error.
5. Resets the index + restores the manifest.

Exact commands (run from project root):

```bash
set -euo pipefail
cp scripts/lib/droplet-manifest.ts /tmp/manifest.bak

# Inject a fake optional entry via in-place edit (use a marker substitution)
node -e "
const fs = require('fs');
const p = 'scripts/lib/droplet-manifest.ts';
const s = fs.readFileSync(p, 'utf8');
const next = s.replace(
  'export const optional: ManifestEntry[] = [];',
  'export const optional: ManifestEntry[] = [\n  { path: \"droplet/__phase8_hook_smoke_test\", purpose: \"smoke\", phase: \"phase-8\", destSubdir: \"\", chmodExec: false },\n];'
);
fs.writeFileSync(p, next);
"

git add scripts/lib/droplet-manifest.ts

# Attempt commit — expect failure
if git commit -m 'phase-8 hook smoke test'; then
  echo "FAIL: commit should have been rejected by pre-commit hook"
  # cleanup
  git reset HEAD scripts/lib/droplet-manifest.ts
  cp /tmp/manifest.bak scripts/lib/droplet-manifest.ts
  exit 1
fi

# Capture stderr separately and assert the staleness message
set +e
err=$(git commit -m 'phase-8 hook smoke test 2' 2>&1)
status=$?
set -e
if [ $status -eq 0 ]; then
  echo "FAIL: second commit attempt also should have failed"
  exit 1
fi
if ! echo "$err" | grep -qF "README.md droplet-manifest section is stale"; then
  echo "FAIL: error message did not contain expected staleness text"
  echo "got: $err"
  exit 1
fi

# Cleanup — restore manifest, drop the index entry
git reset HEAD scripts/lib/droplet-manifest.ts
cp /tmp/manifest.bak scripts/lib/droplet-manifest.ts
rm /tmp/manifest.bak

echo "✓ pre-commit hook correctly rejected the stale-README commit"
```

This task verifies the hook end-to-end. If it passes, the wiring is correct.
</action>
